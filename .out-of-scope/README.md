# Out of scope

Each file here records one idea this repo decided against, and why. Read them before proposing a change; an idea that matches one needs new evidence, not a repeat of the request.

A record has three parts: the decision in one sentence, **Why this is out of scope**, and **Prior requests** (issues, PRs or conversations where it came up, so a repeat can be linked instead of re-argued).
